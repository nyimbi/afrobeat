# Gbẹdu — LLM / ML contributor notes

Living reference for the models and prompts in this repo. Verify against
code before trusting; paths below are relative to the repo root.

## Models in the stack

| Model | Runtime | Purpose | Config |
|-------|---------|---------|--------|
| ACE-Step 1.5 | HuggingFace (`ACE-Step/ACE-Step`) | Primary music + vocal generation | `services/ml/src/gbedu_ml/models/ace_step.py` |
| YuE2-3B-GGUF | audio.cpp `audiocpp_cli` subprocess | Music synthesis slot in the fallback chain | `YUE2_*` envs, `services/ml/src/gbedu_ml/models/yue2.py` |
| Meta-Llama-3-8B-Instruct | transformers, 4-bit (bnb) | Afrobeats lyric generation | `LLAMA_*` envs, `.../inference/lyric_generator.py` |
| Stable Audio Open | HuggingFace | Fallback music backend | `services/ml/src/gbedu_ml/models/stable_audio.py` |
| YuE 7B | HuggingFace | Last-resort fallback backend | `services/ml/src/gbedu_ml/models/yue.py` |
| RVC v2 | local trainer | Voice cloning / conversion | `.../inference/vocal_synthesizer.py`, `RVC_MODELS_DIR` |

Fallback order: ACE-Step → YuE2 → Stable Audio → YuE (see
`services/ml/src/gbedu_ml/inference/music_generator.py`).

## YuE2 settings (`GBEDU_ML_` env prefix)

- Repo: `audio-cpp/Yue2-3B-GGUF`; weights `yue2-3b-q8_0.gguf`, VAE `yue2-vae-f16.gguf`
- `YUE2_THREADS=8`, `YUE2_NUM_INFERENCE_STEPS=8`, `YUE2_COT=full`, `YUE2_TIMEOUT_SECONDS=600`
- CLI kwargs: `lyrics`, `seed`, `cot`, `num_inference_steps`, `style_tags`, `abc`

## Prompt engineering

- Music prompts: `AfrobeatsPromptEngine.build_music_prompt` in
  `services/ml/src/gbedu_ml/prompts/afrobeats.py` (per-subgenre BPM ranges,
  percussion, mood, production style; per-language vocal descriptors).
- Lyric prompts: `build_lyric_prompt` — structured sections
  `[VERSE 1] / [PRE-HOOK] / [HOOK] / [VERSE 2] / [BRIDGE] / [OUTRO]` with
  corpus-derived line/word targets and per-language instructions + quality
  gates (`services/ml/src/gbedu_ml/language/quality_gate.py`).
- Llama-3 sampler: temperature 0.8, top_p 0.92, repetition_penalty 1.15.

## API surface for generation

- `POST /api/v1/generations` — prompt, subGenre, language, energyLevel,
  durationSeconds, bpm?, voiceModelId?, lyrics? (1–5000 chars), seed?.
- `POST /api/v1/lyrics/draft` — lyric-only draft, no quota deduction.
- `POST /voice-models/upload` (Pro+) — RVC training from samples.

## Local commands

```bash
make install            # uv sync --all-packages
make docker-up          # full stack
make test-unit          # fast backend tests, no containers
make test-web           # frontend vitest suite (services/web)
```

## Backend test layout

- `tests/unit/` — API/ML/worker unit tests (no I/O); e.g.
  `test_api_lyrics_routes.py`, `test_ml_pipeline.py`, `test_ml_service_routes.py`.
- No mocks except LLM weights and external payment APIs (repo convention).
