# Large Language Model Configuration Guide

This document contains the full list of LLM configurations used in the Gbẹdu system.

## Base Model: ACE-Step 1.5

| File | Purpose |
|------|---------|
| `libs/ace_step/models/ace_step/models/ace_step1/1400000000/adapter_config.json` | Adapter configuration |
| `libs/ace_step/models/ace_step/models/ace_step1/1400000000/config.json` | Model configuration |
| `libs/ace_step/models/ace_step/models/ace_step1/1400000000/model.safetensors` | Model weights (140M) |
| `libs/ace_step/models/ace_step/models/ace_step1/1400000000/special_tokens_map.json` | Special token mapping |
| `libs/ace_step/models/ace_step/models/ace_step1/1400000000/vocab.txt` | Vocabulary |

> ⚠️ The model weights have been modified in training to enforce specific output constraints rather than being purely generative.

## System Role Instructions by Use Case

**Lyrics Generation**

```
You are an expert lyricist specializing in African music traditions, particularly:
- Afrobeats, Amapiano, Ukulele, Afro-Pop, Alto
- You understand rhythm patterns, vocal flow, and culturally resonant themes.
- Generate lyrics that tell a story with structure: verse-chorus-verse-chorus-bridge-chorus-outro
- Output ONLY the lyrics, nothing else. No explanations, no introductions.

Format:
[PRE-CHORUS]
[CHORUS]
[VERSE]
[HOOK/CHORUS]
[VERSE]
[BRIDGE]
[CHORUS]
[OUTRO]

[Note: Mark structural sections clearly. Ensure rhymes and rhythm flow naturally.]
```

**Music Synthesis Prompt (ACE Step 1.5)**

```
Format your response EXACTLY as:
{{prompt}}
Format: Your complete response must be VALID JSON. JSON should only contain a single object with exactly one key-value pair. The key should be "prompt" and the value should be your full response. Do not include any text outside the JSON.
```

**System Prompts for ACE-Step 1.5:**

| Purpose | Prompt |
|---------|--------|
| Songwriting | Create 100 tokens of lyrics that describe a dream about finding something that once belonged to you. |
| Songwriting 2 | Write an original Amapiano song with a 16 bar verse and an 8 bar chorus. |
| Songwriting 3 | Write a 3 verse song about a love lost and found with Amapiano music |
| Songwriting 4 | Write a 3 verse song about friendship and moving forward together |
| Songwriting 5 | Write a 3 verse song about hope and resilience through hardship |
| Songwriting 6 | Write a 3 verse song about a journey inward, finding yourself and your purpose |
| Translation | Translate the given lyrics from one language to another while preserving meaning, rhythm and rhyme |
| Style Reference | Adapt lyrics to a new genre while maintaining the original meaning and emotion |

## Prompt Engineering

When using LLMs in the Gbẹdu system, follow these formatting guidelines:

### For text-based models:
- Provide constraints and formatting requirements in the system prompt
- Define expected output format explicitly
- Use "ONLY" and "EXACTLY" to enforce format compliance
- Give examples of good responses

### For music generation (ACE-Step):
```
Generate [style] music at [bpm] BPM with [mood] mood and [mood_adjective] feeling.
Generate [genre] music featuring [instruments].
```

## Model Management

- Models are cached in `/models/` once downloaded
- Pre-download models with:
```bash
docker compose exec ml python -c "from gbedu_ml.models import preload_all; import asyncio
asio.run(preload_all())"
```

## Troubleshooting

- **Python crash on import**: `pip install -r requirements/base.txt`
- **CUDA/GPU not detected**: Ensure NVIDIA drivers are installed or use `torch.backends.mps enabled=True` for Apple Silicon
- **Out of memory**: Reduce model precision with `--quantization q4_k_s` or use CPU backend

## Quick Start

```bash
# Setup dependencies
uv sync

# Start the local server (dev mode)
uv run gbedu-web:run

# Run inference locally
uv run python generate_song.py \
    --model ace_step \
    --output song_output.wav
```
